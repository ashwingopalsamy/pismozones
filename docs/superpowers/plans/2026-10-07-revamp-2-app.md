# Pismo Zones Revamp — Plan 2 of 3: State and App

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the signals state layer and the complete Preact UI on top of Plan 1's core, matching the redesign canvas on phone and desktop. This covers live and pinned time, inline edit, the ruler, the command bar, Plan, the sheets, i18n and accessibility.

**Architecture:**
- **State:** `src/state` exposes `createAppState(env)`, a factory that returns signals and actions. All globals (storage, clock, location, language, colour scheme, analytics transport) arrive through `env`, so every test builds a fresh, deterministic state.
- **UI:** `src/ui` renders state through Preact components with co-located CSS Modules. Each component with non-trivial logic has a pure `model.ts` function that is unit-tested separately from rendering.
- **Clock:** only `<LiveSeconds>` subscribes to the 1 Hz clock. Everything else updates at minute granularity.

**Tech Stack:**
- Preact and `@preact/signals`
- CSS Modules
- Vitest with jsdom, `@testing-library/preact`, `@testing-library/user-event`
- Playwright and `@axe-core/playwright`

**Spec:** `docs/superpowers/specs/2026-10-07-pismozones-revamp-design.md` (§3, §6, §7). **Visual reference:** `docs/design/redesign-canvas/*.dc.html`. Copy the CSS values from there wherever this plan says "per canvas".

**Depends on:** Plan 1 (`2026-10-07-revamp-1-foundation-core.md`) being complete.

## Global Constraints

- Everything in Plan 1's Global Constraints still applies.
- **Breakpoints:** phone `< 768px`; wide `≥ 768px` (top bar); desktop `≥ 1024px` (Plan panel always visible under the cards).
- **Cards:**
  - phone 124 px tall, desktop 152 px
  - radius 26/28 px
  - horizon at `0.645 × height`
  - sun-path scale `0.00565 × height` px per degree
  - star count: 26 on phone, 34 on desktop
- **Tokens only:** component CSS uses `var(--…)` tokens from `src/ui/styles/tokens.css`. No raw colours outside `tokens.css` (Task 1 test). No `!important`.
- **Minimums:** text never below 11 px; phone inputs ≥ 16 px; touch targets ≥ 44 × 44 px.
- **Rendering:** only `<LiveSeconds>` may subscribe to `clock.now`. Every other component reads `minuteNow` or `moment`.
- **Copy:** all user-visible copy comes from `src/ui/i18n` (Task 2). There are no literal strings in components except the brand "Pismo Zones".
- **Accessibility:** WCAG 2.2 AA. Every interactive element is a real `<button>`, `<a>`, `<input>` or `<dialog>`, and icon-only buttons carry `aria-label`.
- **Motion:** `prefers-reduced-motion: reduce` disables the pulses, sky and sun transitions, the digit roll and the sheet transitions.
- **Shared fixtures:**
  - `NOW = Date.UTC(2026, 9, 7, 14, 22)`
  - viewer zone `Asia/Kolkata`
  - locale `en-GB`
  - `makeEnv()` test helper (Task 3)

## Review Focus

1. **Storage that throws or holds garbage** (Safari private mode, quota, hand-edited JSON). The app boots with defaults and never shows the error boundary. Test: Task 3 (`survives broken storage`).
2. **Returning to a backgrounded tab after hours.** The clock must resync immediately rather than wait for a throttled timer. Test: Task 4 (`resyncs when the tab becomes visible`).
3. **A viewer outside every office zone** (e.g. `America/New_York`). There is no You tag and the reference defaults to São Paulo, while the header shows "You · 10:22". Test: Task 4 (`viewer outside office zones`) and Task 8 (`YouChip`).
4. **Fast typing then Enter, or Esc pressed twice.** Commit must use the latest text, a cleared field must leave no stale preview, and the second Esc returns to Live. Test: Task 11 (`commits the latest text`, `double Esc`).
5. **Opening a shared link containing offices outside the viewer's list.** They appear as temporary cards, the saved list is untouched, and exiting restores the viewer's own view. Test: Task 5 (`overlay never persists`).

      - office → its name
      - zone → its label
      - clock → `formatClock`
      - text → as is
  - `completion(query: string): string | null` — the alias that completes the final word (≥ 2 chars, prefix match, shortest alias wins), returned as the full query with that word completed.

    - **Enter:**
